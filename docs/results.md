# 6. 방법 비교 결과

파일럿 표본(11.5만 그룹)에서 묶는 규칙 6계열 × 임베딩 4종, 30여 조합을 같은 평가 쌍으로 쟀다. 방법마다 **각자 가장 좋은 기준**에서 비교한다. 같은 숫자의 기준끼리 비교하면 안 된다([3장](tree.md)).

## 묶는 규칙: 평균 연결이 1등

품목(표기 변형) 수준 F1, 규칙별 최고 조합이다.

| 규칙 | 최고 조합 | 품목 F1 [95% CI] | 진 이유 |
|---|---|---|---|
| **평균 연결** | OpenAI 512 · 0.65 | **0.824** [0.799–0.848] | — |
| 철자 + 평균 연결 | OpenAI 512 | 0.796 | 철자 유사도를 섞으면 오히려 떨어짐 |
| Leiden (그래프 커뮤니티) | Gemini 지시문 없음 · CPM | 0.796 | 낮고, γ 마다 분할이 따로 나와 중첩되지 않음 |
| 단일 연결 | OpenAI 512 · 0.85 | 0.786 | 체이닝 — 최대 군집이 BL 38% |
| k-means | OpenAI 512 · k=1000 | 0.761 | 모든 품명을 억지로 k 개에 넣음 |
| UMAP + HDBSCAN (BERTopic 방식) | OpenAI 512 | 0.710 | 품명의 24~44% 를 '소속 없음'으로 버림 |
| 기준선: 전부 한 군집 | — | 0.655 | — |

평균 연결 1위(OpenAI 1536 · 0.827, 512 와 사실상 같음)와의 차이는 다른 규칙 모두 신뢰구간이 0 을 품지 않는다(유의). 게다가 기준을 바꿔 잘라도 군집이 서로 포함되는 트리는 평균 연결만 만든다. **규칙은 이 결과로 확정**했다.

## 임베딩: 수준마다 1등이 다르다

예전 벤치는 범주 BA 를 무작위 쌍을 포함해 쟀다(Gemini 0.887, OpenAI 0.867, 차이 유의하지 않음). 무작위 쌍을 빼고 2겹 교차로 다시 재면 이렇다.

| 비교 | OpenAI | Gemini | 차이 |
|---|---|---|---|
| 품목 F1 | 0.818 | 0.786 | OpenAI +0.032 (무작위 분할 200번 모두 OpenAI 우세) |
| 범주 BA | 0.795 | 0.849 | Gemini +0.054 (200번 모두 Gemini 우세) |
| 범주 BA, 철자 이웃에서 뽑은 쌍만 | 0.829 | 0.875 | Gemini +0.046 (90%) |

셋째 줄은 OpenAI·Gemini 어느 쪽 이웃에서도 뽑지 않은 쌍만 쓴, 편이 없는 부분집합이다(음성 22쌍).

곡선에서 읽을 것 세 가지.

1. **무작위 쌍은 기준을 아래로 끌어당긴다.** 무작위 쌍을 넣으면 OpenAI 범주 BA 가 기준을 낮출수록 계속 올라 0.45 에서 최고가 된다. 무작위 쌍은 아무리 합쳐도 떨어져 있어서, 많이 합칠수록 손해 없이 점수만 오르기 때문이다. 예전 권고 0.45 는 여기서 나왔다.
2. **OpenAI 범주 곡선은 평탄하다.** 0.625~0.425 가 0.796~0.817 이라, 최고점 하나보다 구간으로 봐야 한다. 반으로 나눠 기준을 고르는 일을 400번 해 보면 OpenAI 범주는 0.575 가 164번이고 나머지는 0.475~0.625 로 흩어진다. Gemini 범주는 0.860(154번)과 0.840(139번)에 모인다.
3. **품목은 OpenAI 0.60~0.65, Gemini 0.91** 에 모인다(400번 중 OpenAI 0.600 144번·0.650 130번, Gemini 0.910 152번).
