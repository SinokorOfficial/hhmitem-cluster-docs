# 2. 임베딩과 유사도

## 뜻을 좌표로

임베딩 모델에 품명 문자열을 넣으면 숫자 수백 개짜리 벡터가 나온다. 학습된 모델이라 뜻이 비슷한 문장은 비슷한 방향을 가리킨다. 두 벡터가 얼마나 같은 방향인지를 **코사인 유사도**로 잰다.

\[
\cos(a, b) = \frac{a \cdot b}{\lVert a \rVert \, \lVert b \rVert}
\]

벡터를 길이 1 로 맞춰 두면(단위 벡터) 코사인은 그냥 내적이다. 1 이면 같은 방향, 0 이면 무관하다. 거리로 쓸 때는 \(1 - \cos\) 를 쓴다.

| 모델 | 차원 | 쓰임 |
|---|---|---|
| OpenAI text-embedding-3-large | 512 (1536 의 앞부분을 잘라 다시 정규화) | 주 트리 |
| Google gemini-embedding-2 | 768, 앞에 군집용 지시문(`task: clustering`)을 붙임 | 비교 |
| Gemini 지시문 없음 | 768 | 비교 |
| OpenAI 1536 | 1536 | 비교 — 512 와 결과가 사실상 같아 512 유지 |

## 왜 철자 비교로는 안 되나

같은 물건 쌍을 정밀도 95% 로 골라내는 유사도 기준을 찾아보면, OpenAI 는 0.975, Gemini 는 0.990 에서 가능했지만 철자 비교(문자 n-gram 등)로는 그런 기준이 없었다. `IPA` 와 `ISOPROPANOL`, `AL` 과 `ALUMINUM` 처럼 철자가 전혀 다른 같은 물건, `PP RESIN` 과 `PP WOVEN BAGS` 처럼 철자는 겹치는데 다른 물건이 많기 때문이다.

## 숫자 감 잡기 (OpenAI, 평균 연결 기준)

| 유사도 | 이 정도에서 묶이는 것 |
|---|---|
| 0.90 이상 | 거의 같은 표기 |
| 0.70 근처 | 오타·표기 변형 |
| 0.65 | 품목(같은 물건) 수준으로 권하는 절단 |
| 0.55 | "레진" — PP·PE·ABS·PC 수지가 한 덩어리 |
| 0.475 | 플라스틱 스크랩까지 들어온다 |

!!! warning "모델마다 눈금이 다르다"
    Gemini 는 유사도가 높은 쪽에 몰려 있다. 재질이 다른 수지 쌍의 코사인 중앙값이 OpenAI 0.762, Gemini 0.948 이다. 그래서 같은 0.9 라도 뜻이 다르고, 모델끼리는 숫자가 아니라 **군집 수가 비슷한 지점끼리** 비교해야 한다. Gemini 0.86 은 군집 수로 보면 OpenAI 0.55~0.575 쯤이다.

## 임베딩의 약점: 재질

네 품명 사이의 실제 OpenAI 코사인이다.

| | PP RESIN | POLYPROPYLENE RESIN | PE RESIN | POLYETHYLENE RESIN |
|---|---|---|---|---|
| **PP RESIN** | — | 0.773 | **0.897** | 0.761 |
| **POLYPROPYLENE RESIN** | 0.773 | — | 0.761 | 0.853 |
| **PE RESIN** | 0.897 | 0.761 | — | 0.836 |

같은 물건인 `PP RESIN`–`POLYPROPYLENE RESIN`(0.773)보다, 다른 물건인 `PP RESIN`–`PE RESIN`(0.897)이 더 가깝다. 모델이 "약어 두 글자 + RESIN" 이라는 겉모양에 끌린다. 전체 데이터로 보면 OpenAI 는 다른 재질 쌍(중앙값 0.762)과 약어↔풀네임 쌍(0.782)을 거의 구별하지 못한다.

"약어 품명에 풀네임과 다른 재질 품명 중 어느 쪽이 더 가까운가"를 맞히는 시험에서 OpenAI 는 0.66~0.73, Gemini 는 0.88 을 맞혔다. Gemini 가 재질을 더 잘 가르지만 완벽하지 않다. 이 약점은 [9장](decisions.md)에서 다시 다룬다.
