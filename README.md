# hhmitem-cluster-docs

선적 품명(HHMITEM) 군집 프로젝트의 공개 개발 문서다. 사이트: https://sinokorofficial.github.io/hhmitem-cluster-docs/

- 공개 리포라서 실데이터(BL 건수, 고객사, 내부 시스템 주소)는 넣지 않는다. 코드와 원자료는 비공개 리포에 있다.
- `docs/` 나 `mkdocs.yml` 을 main 에 푸시하면 GitHub Actions 가 Pages 로 배포한다.

로컬 미리보기:

```bash
uvx --with mkdocs-material mkdocs serve
```
